# Mobile

Expo SDK 54 기반 휴대폰 앱 영역입니다.

## 현재 포함된 화면

- 홈
- 카메라 연습
- 악보
- 집중 연습
- 톤메이킹
- 공부하기
- 연습 기록
- 촬영 영상
- 웹 연결
- 설정

## 실행

```bash
npm install
npm start
```

Expo 개발 서버에 표시되는 QR을 휴대폰 Expo Go로 스캔합니다.

## 현재 검증 범위

- TypeScript 정적 검사
- Expo Android 번들 내보내기
- 화면 이동용 정적 UI

## 아직 작동한다고 보고하지 않는 기능

- 실제 카메라·마이크 입력
- 촬영 영상 저장과 1분 분할
- 실시간 자세·음성 분석
- 음성 피드백
- 악보와 음원 동기화
- 웹 실시간 연결

실제 휴대폰에서 화면을 열어보기 전까지 Expo Go 실행 성공으로 보고하지 않습니다.
