# 기타 코치 AI 0.6.0 완성형 베타 계획

## 개발 원칙

- 기존 0.5.4 안정판은 변경하지 않는다.
- 별도 패키지 `com.seungjae.guitarcoach.livetest`에서만 개발한다.
- 첫 화면에서 `통기타` 또는 `일렉기타`를 선택한다.
- 선택한 기타 모드에 따라 연습 메뉴, AI 분석 기준, 악보 형식, 장비와 톤 기능이 자동으로 바뀐다.
- 아래 범위를 모두 구현한 뒤 기능 추가를 멈춘다.
- 이후에는 휴대폰 검수표 순서대로 오류, 성능, 정확도만 수정한다.
- 실제로 판정할 수 없는 항목은 결과를 꾸며내지 않고 `판정 불가`와 촬영 개선 안내를 표시한다.
- 영상·음성 분석은 가능한 범위에서 휴대폰 안에서 처리하며 월 고정비가 생기는 서버 기능은 기본값으로 사용하지 않는다.

- 통기타 모드 / 일렉기타 모드 선택
- 마지막 선택 모드 기억
- 홈, AI 집중 연습, 곡 연습, AI 악보, 카메라·녹화, 기록, 장비·톤, 설정
- 휴대폰 세로 화면 중심 UI
- 카메라 전·후면 전환
- 녹화, 갤러리 저장, 최근 촬영 확인
- 앱 업데이트 설치 시 기존 설정과 기록 보존
- 기능이 실제 연결되지 않은 빈 메뉴는 표시하지 않음

## 3. 통기타 모드

### 연습 종류

- 기본 코드와 코드 전환
- D→G, Cadd2와 분수코드처럼 사용자가 어려워한 전환을 사용자 루틴에 저장
- 코드 한 번에 잡기, 손가락 도착 순서, 불필요한 손가락 들림
- 핑거링과 왼손 독립성
- 아르페지오 P-i-m, P-i-p-m, p-a-m-i와 사용자 패턴
- 엄지 끊김, 검지 전진 후 느린 복귀, 손가락 동반 움직임
- 스트럼 다운·업, 팜뮤트, 강약, 악센트
- 다운 5~6줄 / 업 2~3줄 범위
- 피크 끝 2~3mm 접촉을 목표로 한 깊이 교정
- 손목 과긴장, 손목 꺾임, 팔 전체 과동작, 업스트로크 걸림
- 핑거스타일 곡 연습

### 통기타 AI 분석

- 전신 자세, 어깨, 상체 중심, 기타 위치
- 오른팔과 팔꿈치 위치
- 오른손 손목 각도와 이동 범위
- P·i·m·a 손가락 21개 관절 기반 움직임
- 탄현 순서, 간격, 손가락별 움직임 크기, 동반 움직임
- 엄지와 검지·중지 음량 균일성은 마이크 신뢰도가 충분할 때만 분석
- 스트럼 방향, 폭, 속도 일정성, 다운·업 비대칭
- 피크 색상 추적, 영상 기준 각도, 노출량, 줄 가이드 통과
- 코드 전환 전후 왼손 모양 변화량과 손가락별 도착 지연
- 현재 핵심 문제 1개를 크게 표시하고 나머지는 상세 카드로 분리

- 그립 안정도와 최근 흔들림
- 사용자가 선택한 피크 색상 감지
