# 기타 코치 AI 0.6.0 완성형 베타 계획

## 개발 원칙

- 기존 0.5.4 안정판은 변경하지 않는다.
- 별도 패키지 `com.seungjae.guitarcoach.livetest`에서만 개발한다.
- 아래 범위를 모두 구현한 뒤 기능 추가를 멈춘다.
- 이후에는 휴대폰 검수표 순서대로 오류, 성능, 정확도만 수정한다.
- 실제로 판정할 수 없는 항목은 결과를 꾸며내지 않고 `판정 불가`로 표시한다.

## 1. 고급 메트로놈

- BPM 35~220
- 2/4, 3/4, 4/4, 5/4, 6/8, 7/8, 9/8, 12/8
- 4분, 8분, 셋잇단, 16분 분할
- 첫 박 강조 및 악센트 패턴 편집
- 클릭 음원 선택 및 미리듣기
- 클래식, 높은 클릭, 낮은 클릭, 디지털, 부드러운 클릭
- Android 사람 음성 카운트
- 실행 중 BPM, 박자, 분할, 음원 변경
- 카운트인 1~4마디
- 연습 타이머 1~60분
- 자동 속도 증가: 반복 마디 또는 시간 기준
- 화면을 접어도 연속 실행

## 2. 전신 자세 AI

- 얼굴과 머리 중심
- 고개 기울기
- 양쪽 어깨 높이와 기울기
- 팔꿈치와 손목 위치
- 골반과 상체 중심
- 몸이 카메라에서 너무 가깝거나 먼 상태
- 연습 종류별 기준: 아르페지오, 스트럼, 피킹, 코드 전환
- 즉시 피드백, 현재 점수, 최근 평균, 흔들림 추세

## 3. 오른손·피크 근접 AI

- MediaPipe 손 21개 관절 표시
- 엄지와 검지 간격
- 엄지·검지·중지 관절 굽힘
- 손바닥 축과 손목 방향
- 손가락 독립 움직임과 불필요한 동반 움직임
- 그립 안정도와 최근 흔들림
- 선택한 피크 색상 감지
- 피크 노출량, 영상 기준 각도, 감지 신뢰도
- 다운·업 움직임 방향과 스트로크 폭 추정
- 피크 또는 손이 너무 작거나 흐리면 판정 중단 안내

## 4. 왼손 운지 근접 AI

- 검지, 중지, 약지, 새끼손가락 관절 굽힘
- 손가락 벌어짐과 굽힘 편차
- 손목 방향과 손바닥 회전
- 특정 손가락의 늦은 이동과 불필요한 들림 추정
- 코드 전환 전후 손 모양 변화량
- 최근 평균과 안정도 추세

## 5. 박자 동기화 분석

- 카메라 움직임과 메트로놈 박의 시간 관계 기록
- 오른손 움직임 주기 추정
- 박보다 빠름, 느림, 일정함 표시
- 연속 박의 편차와 안정도 표시
- 마이크 분석을 켠 경우 어택 시점 보조 감지
- 카메라만으로 확정할 수 없는 음정과 줄 번호는 판정하지 않는다.

## 6. 연습 세션

- 연습 종류와 목표 BPM 선택
- 시작 전 카메라 배치 안내
- 실시간 핵심 경고는 최대 1개만 크게 표시
- 나머지 분석은 상세 카드에서 확인
- 세션 시간, 평균 점수, 최고 안정 구간, 반복 문제 저장
- 최근 세션 비교
- 다음 연습 과제 자동 제안

## 7. 설정과 안전장치

- 전면·후면 카메라 전환
- 좌우 반전 보정
- 분석 간격과 저전력 모드
- 음원, 음성, 진동 개별 설정
- 카메라와 분석은 휴대폰 안에서 처리
- 앱 백그라운드 전환 시 카메라 분석 중지
- 메트로놈 중복 실행 방지
- 장시간 실행 시 임시 이미지 정리

## 8. 완성형 베타 휴대폰 검수 순서

1. 앱 설치와 시작 오류
2. 메트로놈 지속·정지·BPM 변경
3. 모든 음원과 사람 음성
4. 전신 자세 골격과 피드백 변화
5. 오른손 손가락 21개 관절
6. 피크 색상·각도·노출량
7. 왼손 손가락 굽힘과 벌어짐
8. 카메라와 메트로놈 동시 실행
9. 10분 연속 실행의 발열·지연·종료 여부
10. 세션 결과와 최근 기록

## 완성 판정

- TypeScript 검사 성공
- Expo Android 번들 성공
- Kotlin 네이티브 ARM64 APK 빌드 성공
- 필요한 AI 모델이 APK 안에 포함됨
- 삼성폰에서 위 검수 10단계를 모두 통과함
- 통과 후에만 안정판 통합 여부를 결정함
