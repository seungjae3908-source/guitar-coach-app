# Web

React 19 + Vite 8 기반 컴퓨터·태블릿용 큰 화면입니다.

## 현재 포함된 화면

- 10개 주요 메뉴 사이드바
- 큰 악보와 현재 마디 강조 UI
- 연주 점수와 세부 지표
- 가장 중요한 교정사항
- 연습 타임라인
- 휴대폰 연결 상태 UI
- 작은 화면 반응형 레이아웃

## 실행

```bash
npm install
npm run dev
```

운영 빌드 확인:

```bash
npm run build
```

## 현재 검증 범위

- Vite 운영 빌드
- 메뉴 이동용 정적 UI
- 반응형 CSS

## 아직 작동한다고 보고하지 않는 기능

- QR 또는 동일 사용자 연결
- 휴대폰 실시간 데이터 수신
- 악보 재생시간 동기화
- 음성 피드백 출력 전환
- 실제 점수와 타임라인 저장

현재 표시되는 점수와 피드백은 화면 확인용 데모 데이터입니다.
