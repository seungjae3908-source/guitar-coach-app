# Architecture Boundary

## 핵심 구성

```text
휴대폰 Expo 앱
  ├─ 카메라·마이크 입력
  ├─ 영상 원본 로컬 저장
  ├─ 실시간 분석 결과 생성
  └─ 점수·현재 마디·피드백 이벤트 전송
           ↓
가벼운 실시간 연결 서버
           ↓
컴퓨터·태블릿 웹 화면
  ├─ 악보와 현재 마디
  ├─ 점수와 교정사항
  └─ 연습 타임라인
```

## 데이터 경계

### 휴대폰에 기본 저장

- 전체 연주 원본 영상
- 1분 분할 영상
- 사용자가 직접 자른 영상
- 자동 생성된 틀린 구간 클립
- 긴 오디오 원본

### 서버·데이터베이스 저장 후보

- 곡과 연습 세션 식별정보
- 시작·종료 시간과 연습 길이
- 마디, 문제 원인, 점수
- 분석 상태와 검증 상태
- 휴대폰 내부 클립을 찾기 위한 로컬 참조값

### 웹으로 우선 전송

- 현재 마디
- 실시간 점수
- 핵심 교정사항 1~2개
- 피드백 이벤트와 타임라인
- 연결 상태

초기 단계에서는 영상 전체 스트리밍을 사용하지 않습니다.

## 비용 경계

- 무료 호스팅과 무료 데이터베이스 범위를 우선합니다.
- 유료 AI API, 유료 영상 저장소, 유료 스트리밍은 사용자 승인 전 도입하지 않습니다.
- 비용 기능을 제안할 때는 예상 금액, 과금 단위, 필요한 이유를 먼저 기록합니다.

## 기능 상태 표현

각 기능은 다음 중 하나로 기록합니다.

1. 미구현
2. 구현됨·미테스트
3. 수동 테스트 통과
4. 자동 테스트 통과
5. 실제 휴대폰 테스트 통과

`정상 작동`은 필요한 실제 환경 테스트까지 통과한 경우에만 사용합니다.
