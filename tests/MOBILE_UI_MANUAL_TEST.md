# Mobile UI Manual Test

대상: Expo Go가 설치된 실제 휴대폰

## 시작 전

- 테스트 링크 또는 QR은 `guitar-coach-app` 프로젝트에서 생성된 것만 사용합니다.
- 주식 앱 프로젝트의 QR이나 주소를 사용하지 않습니다.
- 카메라·마이크 권한은 이번 UI 테스트에서 필요하지 않습니다.

## 확인 항목

1. 앱 첫 화면이 흰 화면이나 강제 종료 없이 열리는지 확인
2. 상단 가로 메뉴를 좌우로 이동할 수 있는지 확인
3. 홈, 카메라 연습, 악보, 집중 연습, 톤메이킹, 공부하기, 연습 기록, 촬영 영상, 웹 연결, 설정을 각각 열기
4. 하단 메뉴의 홈, 카메라, 악보, 집중, 설정 이동 확인
5. 카메라 화면에 `UI 초안 · 카메라 미연결` 문구가 표시되는지 확인
6. 악보 화면에 흰 종이 형태, 코드, 리듬, 가사, 마디 번호, 타브가 표시되는지 확인
7. 집중 연습의 코드·핑거링·아르페지오·스트럼·피킹 버튼이 선택되는지 확인
8. 글자가 겹치거나 화면 밖으로 잘리는 위치 기록
9. 앱이 멈추거나 종료되는 동작 기록

## 성공 기준

- 앱 첫 화면이 정상적으로 열림
- 10개 메뉴를 모두 이동할 수 있음
- 버튼을 눌러도 강제 종료되지 않음
- 기능 미연결 안내가 명확하게 표시됨

이번 테스트 성공은 UI 실행만 의미합니다. 카메라, 마이크, 녹화, 분석, 음성 피드백 기능의 성공을 의미하지 않습니다.
